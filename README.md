# Bee Bambu Studio Release

Kho lưu trữ và phát hành các bản build của **Bee Bambu Studio** dành cho **macOS** và **Windows**.

## 🚀 Tải về phiên bản mới nhất

Truy cập mục [Releases](https://github.com/lqdung95ntp/bee-bambu-studio-release/releases) để tải tệp cài đặt phù hợp với hệ điều hành của bạn:

| Hệ điều hành | Tệp tải về (Assets) | Mô tả |
| :--- | :--- | :--- |
| **Windows** | `BambuStudio_Windows_x64_Portable_2.9.1.70.zip` | Bản Portable cho Windows x64 (giải nén chạy ngay) |
| **macOS** | `BambuStudio_MacOS_Universal_2.9.1.70.dmg` | Bản Universal hỗ trợ cả chip Apple Silicon (M1/M2/M3/M4) và Intel |

---

## 📌 Hướng dẫn sử dụng

### 1. Windows
1. Tải về file `BambuStudio_Windows_x64_Portable_*.zip` từ mục **Releases / Assets**.
2. Giải nén file `.zip` vào thư mục mong muốn.
3. Chạy file `bambu-studio.exe` để bắt đầu sử dụng.

### 2. macOS
1. Tải về file `BambuStudio_MacOS_Universal_*.dmg` từ mục **Releases / Assets**.
2. Mở file `.dmg` và kéo ứng dụng vào thư mục `Applications`.
3. Nếu gặp thông báo bảo mật của macOS (*"unidentified developer"*):
   - Mở **System Settings** > **Privacy & Security**.
   - Cuộn xuống phần Security và nhấn **Open Anyway**.
